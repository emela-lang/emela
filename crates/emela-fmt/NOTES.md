# formatter の補足

仕様（草案 2026-10-07）に書かれていない判断を残す．

# 入出力

- （補）既定の幅は 100．幅は表示幅で数える（全角の文字は2）．文字列や名前が長くて収まらない行は幅を超える
- （補）構文エラーのあるファイルは整形しない（`FormatError::Syntax`）．この段のパーサが読まない宣言（type enum など）も ERROR ノードになるので整形しない
- （補）整形の結果を読み直し，構文エラーがないこと，トークン列とコメントの並びが入力と一致することを確かめる．一致しなければ `FormatError::Internal` を返し，入力を書き換えない
- （補）改行は LF にそろえ，行末の空白を消し，ファイルは改行1つで終える．空のファイルは空のまま

# 空白と改行

- （補）インデントは空白2つ
- （補）連続する空行は1つにまとめる．ファイル，ブロック，腕の並びの先頭と末尾の空行は消す．引数などの並びの中の空行も消す
- （補）トップレベルの宣言の間の空行は元のまま（0か1）にし，足さない
- （補）演算子の前後，`,` の後ろ，`:` の後ろに空白1つ．`:` の前，括弧の内側，`.` と `..` の前後には置かない．効果の集合の波括弧だけは内側に空白を置く（`use { Io, Clock }`）
- （補）名前付き引数とフィールドのパターンの省略形（`id:`）はそのまま残す．`id: id` を省略形に書き換えることもしない

# ブロックと制御構文

- （補）ブロックと腕の並び（match，escape）は，元のソースで1行（改行なし，文や腕が1つ以下）なら，幅に収まるかぎり1行のままにする．元が複数行なら複数行にする．空のブロックは `{}`
- （補）if，else if，else のブロックは1つの group として折る．どれかが複数行なら全部複数行にする
- （補）`}⏎else {` は `} else {` にそろえる．ただし `}` の後ろに行末のコメントがあれば，`else` は次の行に置く（継続の規則 2.5 で読める）
- （補）match と escape の腕の `->` は，同じ並びの中で1行に収まる腕だけ揃える．揃えると幅を超える腕があれば，頭（パターンとガード）が最も長い腕を揃えから外してやり直す．中にコメントのある腕は揃えない
- （補）束縛の `=` は揃えない（仕様 8.2 の例は揃えているが，1行足すと周りの行まで差分になる）
- （補）行末のコメントの前は空白1つにし，揃えない（仕様の例は揃えているが，束縛の `=` と同じ理由）

# 折り返し

- （補）引数，仮引数，タプル，リスト，型引数，パターンの引数は，収まれば1行で末尾のカンマを取り，収まらなければ1要素1行で末尾のカンマを付ける．元のソースの末尾のカンマは折り方に影響しない．ただし最後の要素に行末のコメントがあり元にカンマがなければ，カンマを足さない（コメントの中に入ってしまうため）
- （補）最後の引数がブロックを持つ無名関数（名前付き引数の値でもよい）なら，ほかの引数が1行に収まり，`f(xs, fn(x) {` までが幅に収まるかぎり，括弧を開いたまま本体を抱え込む
- （補）二項演算子は，同じ強さの演算子の鎖をまとめて，演算子の前で折り，1段下げる．`-` の前では折らない．行頭の `-` は単項マイナスとして新しい文になる（2.5）ため
- （補）パイプは，元のソースで `|>` の前に1か所でも改行があれば全部折る．なければ幅で決める．パイプが1つで，右辺が抱え込んだ無名関数で折れるときは，1行目が収まればパイプを折らない（`xs |> List.map(fn(x) {`）
- （補）束縛の `=` の後ろ，腕の `->` の後ろでは折らない．行頭の式は新しい文になるため
- （補）関数の宣言では引数の並びだけを折り，`->`，`fails`，`use` の節は `)` と同じ行に置く
- （補）文字列の補間 `#{ }` の中は折らない（中の空白は整える）．中にコメントがあるときだけ元の改行を保つ

# コメント

- （補）コメントは，前のトークンと同じ行にあれば直前のトークンに，自分の行にあれば直後のトークンに付ける
- （補）宣言，文，腕，並びの要素，演算子，閉じ括弧の前のコメントは，その行の字下げで前に置く．それ以外の位置（`.` や `escape` の前，型引数の中など）のコメントは，付いたトークンの前後にそのまま出し，必要なら改行を入れる．そこは括弧の中か継続の位置なので，改行を入れても読み方は変わらない
- （補）`##` のドキュメントコメントも，整形では `#` のコメントと同じに扱う
